# Database layer

Firestore is the canonical database. The browser uses Firebase anonymous authentication and is limited by `database/firestore.rules` to public reads and validated creates in the `birthdayWishes` collection. Updates and deletes are denied.

Each document contains:

- `name`
- `message`
- `createdAt`
- `createdAt` generated by Firestore server timestamp

The free-tier browser path uses Firestore-generated document IDs. The paid-tier Cloud Functions adapter can add deterministic IDs and GitHub archival later without changing the public form contract.
